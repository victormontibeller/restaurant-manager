# Decisões arquiteturais — ADRs

[Índice da documentação](../README.md)

Esta pasta receberá registros de decisões arquiteturais relevantes. Não há ADR de implementação aprovado neste estágio. As decisões de produto confirmadas continuam em [Visão do projeto](../00_PROJECT_VISION.md).

## Quando registrar

Registre uma escolha quando seu contexto, alternativas e consequências forem necessários para entender uma mudança relevante de arquitetura, segurança, integração ou operação. Não criar ADR para toda alteração pequena ou apenas para repetir uma regra existente.

## Formato

Use nome sequencial `NNNN-assunto.md`, com título e estas seções:

- **Status:** proposto, aceito ou substituído; informar data e referência de validação quando existir.
- **Contexto:** problema, restrições e decisão/premissa relacionada.
- **Decisão:** escolha e limites; alternativas relevantes consideradas.
- **Consequências:** impactos, riscos, verificação e documentos afetados.

Uma proposta não ganha status aceito pela criação do arquivo. Ao mudar uma decisão, preserve o histórico do ADR e atualize a fonte do assunto e a sprint afetada. IDs D/P/E permanecem nos registros centrais, sem renumeração automática.
